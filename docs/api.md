# 記事 API

記事を書いて公開し、公開した記事にコメントがつく、小さなブログの API。

ここに書くのは「何を作るか」だけ。ファイルの置き場所、名前、成功の status、失敗の返し方は hono-kit の決まりに従う。

## 登場するもの

- **ユーザー**: 記事とコメントを書く人。名前（前後の空白を除いて 1〜50 文字）を持つ
- **記事**: ユーザーが書く。題（前後の空白を除いて 1〜200 文字）と本文（1 文字以上）を持つ。作ったときは下書きで、公開すると誰でも読めるようになる。公開は取り消せて、取り消すと下書きに戻る
- **コメント**: 公開中の記事に、ユーザーが書く。本文（前後の空白を除いて 1〜1000 文字）を持つ

## 認証（仮）

本物のログインはまだ作らない。リクエストの `x-user-id` ヘッダーに書かれた ID のユーザーが、そのリクエストをしている人とする。ヘッダーが無いとき、または ID のユーザーがいないときは、ログインしていない扱い。

組織や役割は無い。ユーザーはみんな同じ立場。

## ルール

- 下書きは書いた本人にしか見えない。本人以外には、無いのと同じに見える
- 記事を変える・消す・公開する・公開を取り消すのは、書いた本人だけ
- コメントは公開中の記事にだけ書ける。公開を取り消した記事のコメントは消さずに残し、公開し直すとまた見える
- 記事を消すと、その記事のコメントも消える
- 一覧はどれも 1 回で全部返さず、続きを取れる形にする

## API

| メソッドとパス                 | 誰が       | すること                                                               |
| ------------------------------ | ---------- | ---------------------------------------------------------------------- |
| `POST /users`                  | 誰でも     | ユーザーを登録する。入力は名前                                         |
| `GET /articles`                | 誰でも     | 公開中の記事の一覧。公開が新しい順。著者の ID と名前、コメントの数つき |
| `POST /articles`               | ログイン中 | 記事を下書きで作る。入力は題と本文                                     |
| `GET /articles/:id`            | 誰でも     | 公開中の記事 1 件。著者の ID と名前、コメントの数つき                  |
| `PUT /articles/:id`            | 著者       | 題と本文を丸ごと変える（下書きでも公開中でも）                         |
| `DELETE /articles/:id`         | 著者       | 記事を消す                                                             |
| `POST /articles/:id/publish`   | 著者       | 下書きを公開する                                                       |
| `POST /articles/:id/unpublish` | 著者       | 公開を取り消して下書きに戻す                                           |
| `GET /articles/:id/comments`   | 誰でも     | 公開中の記事のコメント一覧。古い順。書いた人の ID と名前つき           |
| `POST /articles/:id/comments`  | ログイン中 | 公開中の記事にコメントする                                             |
| `GET /users/:id/articles`      | 誰でも     | そのユーザーが公開中の記事の一覧。公開が新しい順。コメントの数つき     |
| `GET /me/articles`             | ログイン中 | 自分の記事の一覧。下書きも含む。作ったのが新しい順。公開中かどうかつき |

## 失敗

hono-kit が持っている失敗（ログインしていない、入力が正しくない、無い、など）はそれを使う。この API だけの失敗は次のとおり。

| コード              | いつ                           |
| ------------------- | ------------------------------ |
| `ALREADY_PUBLISHED` | 公開中の記事を公開しようとした |
| `NOT_PUBLISHED`     | 下書きの公開を取り消そうとした |

- 本人以外が下書きを読もう・変えよう・消そう・公開しようとしたときは、下書きが無いのと同じ失敗にする（あることを漏らさない）
- 本人以外が公開中の記事を変えよう・消そうとしたときは、権限が無い失敗にする
- 下書きのコメントを読む・書くときは、記事が無いのと同じ失敗にする
- `GET /users/:id/articles` でユーザーがいないときは、無い失敗にする
