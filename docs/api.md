# 記事 API

記事を書いて公開し、公開した記事にコメントがつく、小さなブログの API。

ここに書くのは「何を作るか」だけ。ファイルの置き場所、名前、成功の status、失敗の返し方は hono-kit の決まりに従う。

## 認証（仮）

アカウントの登録とログインは、この API の外（認証の仕組み）の仕事で、まだ作らない。代わりに、リクエストの `x-user-id` ヘッダーに書かれた ID を、検証済みのログイン中の人の ID としてそのまま信じる。ヘッダーが無ければログインしていない。

組織や役割は無い。ログイン中の人はみんな同じ立場。

## 登場するもの

- **プロフィール**: ログイン中の人が、自分で決める表示名（前後の空白を除いて 1〜50 文字）。1 人に 1 つ。あとから変えられる
- **記事**: プロフィールを持つ人が書く。題（前後の空白を除いて 1〜200 文字）と本文（1 文字以上）を持つ。作ったときは下書きで、公開すると誰でも読めるようになる。公開は取り消せて、取り消すと下書きに戻る。もう一度公開すると、公開した日時はその時に変わる
- **コメント**: プロフィールを持つ人が、公開中の記事に書く。本文（前後の空白を除いて 1〜1000 文字）を持つ

## ルール

- プロフィールを持たない人は、記事もコメントも書けない
- 下書きは書いた本人にしか見えない。本人以外には、無いのと同じに見える
- 記事を変える・消す・公開する・公開を取り消すのは、書いた本人だけ
- コメントは公開中の記事にだけ書ける。公開を取り消した記事のコメントは消さずに残し、公開し直すとまた見える
- 記事を消すと、その記事のコメントも消える
- 一覧はどれも 1 回で全部返さず、続きを取れる形にする

## API

| メソッドとパス                 | 誰が       | すること                                                                    |
| ------------------------------ | ---------- | --------------------------------------------------------------------------- |
| `GET /me/profile`              | ログイン中 | 自分のプロフィール                                                          |
| `PUT /me/profile`              | ログイン中 | 自分のプロフィールを作る、または変える。入力は表示名                        |
| `GET /articles`                | 誰でも     | 公開中の記事の一覧。公開が新しい順                                          |
| `POST /articles`               | ログイン中 | 記事を下書きで作る。入力は題と本文                                          |
| `GET /articles/:id`            | 誰でも     | 記事 1 件。公開中の記事は誰でも読める。ログイン中なら、自分の下書きも読める |
| `PUT /articles/:id`            | 著者       | 題と本文を丸ごと変える（下書きでも公開中でも）                              |
| `DELETE /articles/:id`         | 著者       | 記事を消す                                                                  |
| `POST /articles/:id/publish`   | 著者       | 下書きを公開する                                                            |
| `POST /articles/:id/unpublish` | 著者       | 公開を取り消して下書きに戻す                                                |
| `GET /articles/:id/comments`   | 誰でも     | 公開中の記事のコメント一覧。古い順                                          |
| `POST /articles/:id/comments`  | ログイン中 | 公開中の記事にコメントする。入力は本文                                      |
| `GET /users/:id/articles`      | 誰でも     | その人が公開中の記事の一覧。公開が新しい順                                  |
| `GET /me/articles`             | ログイン中 | 自分の記事の一覧。下書きも含む。作ったのが新しい順                          |

## 見せるもの

| どこで                                           | 1 件ごとに見せるもの                                                                                                                          |
| ------------------------------------------------ | --------------------------------------------------------------------------------------------------------------------------------------------- |
| プロフィール                                     | 人の ID、表示名                                                                                                                               |
| `GET /articles`、`GET /users/:id/articles`       | 記事の ID、題、著者（人の ID と表示名）、公開した日時、コメントの数                                                                           |
| `GET /articles/:id` と、記事を書き込んだ後       | 記事の ID、題、本文、著者（人の ID と表示名）、状態（下書きか公開中か）、公開した日時（下書きなら無し）、コメントの数、作った日時、変えた日時 |
| `GET /me/articles`                               | 記事の ID、題、状態、公開した日時（下書きなら無し）、作った日時、変えた日時                                                                   |
| `GET /articles/:id/comments`、コメントを書いた後 | コメントの ID、本文、書いた人（人の ID と表示名）、書いた日時                                                                                 |

コメントの数は、公開を取り消している間のコメントも含めた、その記事のコメントの数。

## 失敗

hono-kit が持っている失敗（ログインしていない、入力が正しくない、無い、権限が無い）はそれを使う。この API だけの失敗は次のとおり。

| コード              | いつ                                                   |
| ------------------- | ------------------------------------------------------ |
| `PROFILE_REQUIRED`  | プロフィールを持たない人が記事かコメントを書こうとした |
| `ALREADY_PUBLISHED` | 公開中の記事を公開しようとした                         |
| `NOT_PUBLISHED`     | 下書きの公開を取り消そうとした                         |

- 本人以外が下書きを読もう・変えよう・消そう・公開しようとしたときは、無いのと同じ失敗にする（あることを漏らさない）
- 本人以外が公開中の記事を変えよう・消そう・公開しよう・公開を取り消そうとしたときは、権限が無い失敗にする
- 下書きのコメントを読む・書くときは、本人でも、記事が無いのと同じ失敗にする
- `GET /me/profile` でまだプロフィールが無いときは、無い失敗にする
- `GET /users/:id/articles` でその人のプロフィールが無いときは、無い失敗にする
